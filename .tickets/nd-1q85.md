# Make OnePlus kernel patchable for bottom-mic tracing

Prerequisite for nd-n819. The OnePlus host currently wraps a known-good fetched linux-7.0.0 closure in hosts/oneplus/oneplus-fajita/hardware/sdm845.nix, so boot.kernelPatches cannot instrument Qualcomm ASoC/ADSP paths. Provide an explicit kernel-development flow that builds or imports a patchable sdm845 linux source at the pinned 77ae339/sdm845-next base, preserves the current modDirVersion/device-tree behavior, and allows focused trace patches for q6afe/wcd934x/slim without destabilizing the normal pinned closure by default.

## Design

Keep normal /aloop on the pinned Attic kernel closure unless explicitly entering kernel development. Add a separate option/overlay/package or documented branch that uses hosts/oneplus/oneplus-fajita/hardware/kernel.nix/buildLinux against inputs.sdm845-linux-oneplus-kernel or a local checkout, then apply focused tracing patches for snd_soc_qcom/q6afe, wcd934x TX ADC/DEC power, and SLIM NGD state. Do not reintroduce Mic1 UCM or static PipeWire source.

## Acceptance Criteria

A maintainer can select a patchable OnePlus kernel source derivation for one boot generation, apply a trivial trace patch to q6afe/wcd934x/slim code, and produce a kernel closure suitable for nd-n819 experiments; the default stable OnePlus config remains on the pinned known-good closure unless explicitly opted in.
